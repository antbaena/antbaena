## 🎓 About Me

I’m a **Ph.D. student in Mechatronics** at the **Machine Perception and Intelligent Robotics (MAPIR)** group, University of Málaga, funded by an **FPU fellowship** and supervised by Cipriano Galindo and Javier González-Jiménez.  
My thesis is about **3D Gaussian Splatting for robots**: scene representations that a robot can load, localize in and understand semantically.  
Before that I did my **B.Sc. in Software Engineering** and my **M.Sc. in Artificial Intelligence & Software Engineering** at UMA, and I’ve been doing research at MAPIR since 2024 on Human–Robot Interaction & Computer Vision with our service robot, Sancho.  
My full portfolio is at [antbaena.github.io](https://antbaena.github.io/)

## 🔬 Featured Projects

- **TopoGS** *(paper in preparation)*  
  My master’s thesis: splitting multi-room 3D Gaussian Splatting maps into per-room submaps using only image covisibility, so a robot can localize with a fraction of the memory. Code coming soon.  
- **[Sancho ROS2 Workspace](https://github.com/antbaena/sancho_ws)**  
  ROS 2 Humble-based modular workspace developed for my final degree project (TFG), featuring multimodal interaction packages, full Nav2 navigation stack, and a modern React/Vite web interface.  
- **[IbimaCam MotionCapture](https://github.com/antbaena/ibimacam-mocap-qt)**  
  Desktop app (PySide6 + ROS 2) that controls 4 hardware-synchronized Orbbec RGB-D cameras on remote Raspberry Pis and records synchronized rosbags, built for a clinical motion-capture project with IBIMA.  
- **[Fake Accounts Instagram](https://github.com/antbaena/Fake-Accounts-Instagram)**  
  Quarto book project in R for detecting fake Instagram accounts through data exploration, feature selection, visualization, regression model building, and implementation of optimized models.
